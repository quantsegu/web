# Shreshti Web

A modern React TypeScript application built with Vite, Tailwind CSS, and Motion.

## Development

Install dependencies:
```bash
npm install
```

Run development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

Preview production build:
```bash
npm run preview
```
